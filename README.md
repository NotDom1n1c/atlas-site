# ATLAS · Website

Website für ATLAS, das lokale Kontrollzentrum für alle Projekte auf dem Laptop.

- **Live:** https://notdom1n1c.github.io/atlas-site/
- **Seiten:** Start, Funktionen, Live-Demo, Handbuch, Versionen
- **Live-Demo:** die echte ATLAS-Oberfläche, die im Browser mit erfundenen Beispieldaten läuft (`demo/`, `demo-api.js`). Es werden keine echten Daten verwendet.

Statische Seite ohne Build-Schritt: HTML, CSS und JavaScript.
