Starten

ATLAS wird über die Verknüpfung auf dem Desktop oder im Startmenü gestartet. Dabei passiert Folgendes:

  1. Der Server atlas.pyw startet ohne Konsolenfenster auf 127.0.0.1:4321.
  2. Edge öffnet ATLAS im App-Modus. Das Fenster hat ein eigenes Symbol in der Taskleiste und lässt sich anheften.
  3. Ein zweiter Doppelklick öffnet nur ein weiteres Fenster, der Server läuft bereits.

Wenn 20 Minuten lang kein Fenster offen ist, beendet sich der Server. Ist eine Automation aktiv, läuft er weiter.

python atlas.pyw --no-window   # nur der Server, zum Testen im Browser

Katalog und Bereiche

Alle Bereiche und Projekte stehen in catalog.json. Ein Projekt hat einen Namen, einen Bereich, einen Status und einen oder mehrere Ordner. Pfade können Kürzel wie {CLAUDE} oder {HOME} verwenden.

{
  "id": "harbor",
  "name": "HARBOR",
  "section": "plattform",
  "status": "live",
  "paths": ["{CLAUDE}/harbor"],
  "live": "https://harbor.user-dev.example/"
}

Status sind Live, Aktiv, Entwurf, Pausiert, Fertig und Archiv. Office-Dateien müssen nicht eingetragen werden: Die Sammlungen werden bei jedem Scan neu gebildet.

Suche

Ctrl K oder / öffnet die Suche. Sie findet Projekte nach Name, Technik und Tags, dazu Dateien in allen Projektordnern. Ganz unten steht «Im Code suchen»: Damit wird der Inhalt aller Textdateien durchsucht, mit Zeilennummer und Sprung in den Datei-Explorer.

Projekt anlegen

«Neu» oben rechts oder N öffnet den Dialog. Pflicht sind Name und Bereich. Ordner, Live-URL, GitHub-Repository und Start-Befehl können später ergänzt werden. Ctrl Enter speichert.

Ein eigenes Titelbild lässt sich auf der Projektseite per Drag and Drop oder mit Ctrl V setzen.

Kontrollzentrum

Dev-Server

Die Liste kommt aus .claude/launch.json. ATLAS startet den Befehl, merkt sich den Prozess und zeigt das Log. Läuft der Port bereits, gilt der Server als gestartet.

VMs und WSL

VirtualBox-Maschinen werden über VBoxManage, WSL-Distributionen über wsl.exe gesteuert.

Monitor

Jede Live-URL wird alle fünf Minuten abgefragt. Die letzten Ergebnisse stehen als Balken neben der Seite, darunter die GitHub-Actions und die Zertifikate.

Automationen

Eine Regel besteht aus einem Auslöser und einer oder mehreren Aktionen. Beim Anlegen zählt der aktuelle Zustand als bereits gesehen, damit nicht alles auf einmal auslöst. Mit «Test» lässt sich eine Regel sofort ausprobieren.

IT-Werkzeuge

Ping, Traceroute, Port-Check und DNS verwenden die Windows-Befehle ping, tracert und Resolve-DnsName. Der Subnetz-Rechner läuft im Browser.

Der Netz-Scan prüft höchstens 254 Adressen und nur in Netzen, die man vorher als eigenes bestätigt hat. Schul-, Firmen- und öffentliche Netze werden erkannt und gewarnt. Dort ist Scannen meist durch die Nutzungsregeln verboten.

Im Server-Verzeichnis werden Name, Adresse, Port und Benutzer gespeichert. Passwörter bleiben im Passwort-Manager.

Darstellung

Das Paletten-Symbol oben rechts oder , öffnet die Einstellungen: Thema, Akzentfarbe, Banner, Grösse, Kontrast und Bewegung. Die Einstellungen gelten pro Gerät.

Unter «GUI-Versionen» stehen alle gesicherten Stände der Oberfläche. «Zurückholen» sichert vorher automatisch den aktuellen Stand.

Daten und Datenschutz

  • ATLAS hört nur auf 127.0.0.1. Andere Geräte im Netz erreichen es nicht.
  • Zwischenspeicher, Vorschaubilder und Einstellungen liegen in C:\Users\<Name>\.atlas.
  • Tokens für Discord und Spotify werden nur lokal gespeichert. Für GitHub wird die bestehende Anmeldung von gh verwendet.
  • Gelöscht wird nur in den Papierkorb und nur nach Bestätigung.
  • Outlook wird nicht im Hintergrund abgefragt, wenn Windows dafür eine Sicherheitswarnung zeigen würde.

Die Demo auf dieser Website läuft komplett im Browser. Sie verwendet Beispieldaten und sendet nichts an einen Server.
